# FC27 public visual reference notes

Public EA FC27 material emphasizes FUT Gallery, 3D player items, Holographic/Pristine items, Icons, Heroes and special campaign cards. FCBaz uses those concepts as product inspiration while keeping its own original component geometry and assets.

Public FUT.GG FC27 surfaces are used as data/reference points for player database, prices, price ranges, squad building, SBCs, Evolutions, Objectives and discovery.
