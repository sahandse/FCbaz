# FCBaz — FUTBIN/FUT.GG parity map

این سند برای جلوگیری از اضافه‌شدن قابلیت‌های نمایشی یا بدون منبع واقعی است. هر قابلیت فقط بعد از اتصال به داده واقعی وارد UI عمومی می‌شود.

## وضعیت فعلی FCBaz

### موجود
- دیتابیس بازیکنان FC27 با منبع رسمی EA + FUT.GG
- جستجو و فیلتر پیشرفته
- جزئیات بازیکن
- Price lookup برای Console / PC در صورت پاسخ منبع عمومی معتبر
- FUTBIN lookup با ID داخلی و EA Resource ID
- فهرست پیگیری محلی
- تیم‌ساز و Chemistry
- SBC Center
- Evolutions
- Objectives
- My Club محلی
- Meta / What's Hot / What's New
- تنظیمات فارسی و RTL
- Data Health + offline last-known-good catalog
- FC27-inspired rarity card UI (Gold/Icon/Hero/TOTW/Holographic/etc.)

## قابلیت‌های مرجع که باید تکمیل شوند

### Players
- Trackers
- Upgrades & Downgrades
- Roles

- Player Game Performance
- Perfect Chemistry
- Version comparison
- Detailed in-game stats برای کارت‌هایی که منبع واقعی برمی‌گرداند

### Squad Builder
- Chemistry breakdown کامل
- Squad price زنده برای کارت‌های دارای قیمت
- Formation selector کامل
- Tactics

- Best player suggestions by position/budget

### SBC
- Active SBCs
- Cheapest Players by Rating

- Best Value SBCs
- Cheapest real solution فقط با منبع معتبر
- Owned-player-aware solution با My Club محلی
- نام Challenge انگلیسی + فارسی فقط در صورت ترجمه معتبر

### Promo / Squads
- Promo Squads
- Team of the Week
- Event squads
- Release date/status

### Evolutions
- Active Evolutions
- Evolution Players
- Popular Evolution Players
- Evolution Builder
- Saved Evolutions محلی
- My Evolutions محلی
- Eligibility checker
- Evolution path comparison

### Market
- Live price
- Price range
- Price history فقط از منبع واقعی
- Market Movers فقط با داده تغییر واقعی
- Cheapest by rating
- Watchlist محلی

### Content
- Objectives

- Game updates

## سیاست ورود/حساب
FCBaz ثبت‌نام و Login ندارد. Watchlist، My Club، Squads و Saved Evolutions روی دستگاه ذخیره می‌شوند.
