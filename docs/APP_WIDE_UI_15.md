# App-wide UI migration checklist

The global 1.5 theme already updates typography, inputs, buttons, chips, cards, dialogs, sheets and navigation across the app. Feature-specific follow-up surfaces use the same tokens.

Priority surfaces:
- Home: compact live hub and player-item carousel.
- Players: FUT collection grid (completed in 1.5 scope).
- Player Details: large item hero + price/stat modules.
- Market: dark data tiles, platform switch and verified-price states.
- SBC/Evolutions/Objectives: compact live-content cards and expiry emphasis.
- Squad Builder: darker pitch, item-shaped slots, chemistry highlight.
- My Club: collection-first rarity grid.
- Search: full-width compact search + item results.
- Settings: grouped dark modules and Data Health.

No screen should introduce a second unrelated palette or generic rounded-card language.
