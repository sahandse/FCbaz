# Store Asset Checklist

## Required creative assets

- App icon: final FCBaz icon
- Feature graphic / promotional banner
- Phone screenshots with real production data
- Dark-mode screenshot set
- Persian RTL screenshot set

## Screenshot rules

- No test/fake player prices
- No private account email unless intentionally anonymized
- No API keys, tokens, server URLs or debug overlays
- Use the release build only
- Keep visual language consistent with the black / neon-green FCBaz identity
