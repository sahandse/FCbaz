# سیاست حریم خصوصی FCBaz

آخرین بروزرسانی: ۲۰ سپتامبر ۲۰۲۶

FCBaz با هدف ارائه ابزارهای مرتبط با FC27 Ultimate Team طراحی شده است.

## اطلاعات ذخیره‌شده روی دستگاه

بخشی از اطلاعات برنامه به‌صورت محلی روی دستگاه ذخیره می‌شوند، از جمله:

- Favorites
- Watchlist و قیمت هدف
- Search History
- Saved Filters
- Squads و تنظیمات Squad
- My Club
- Reviewهای شخصی
- تنظیمات برنامه
- Notification Center

این اطلاعات برای عملکرد خود برنامه استفاده می‌شوند.

## حساب کاربری و Cloud Sync

در صورت استفاده از قابلیت حساب و Cloud Sync، آدرس ایمیل و اطلاعات لازم برای احراز هویت توسط سرویس احراز هویت متصل به FCBaz پردازش می‌شوند.

رمز عبور توسط برنامه به‌صورت متن ساده ذخیره نمی‌شود.

Tokenهای ورود در Secure Storage سیستم‌عامل نگهداری می‌شوند و در Backup محلی یا Cloud Backup داده‌های برنامه قرار نمی‌گیرند.

## Backup

کاربر می‌تواند از داده‌های FCBaz Backup تهیه کند. Backup فقط داده‌های متعلق به FCBaz را شامل می‌شود.

کاربر مسئول نگهداری امن فایل یا متن Backup خود است.

## اعلان‌ها

در صورت فعال‌سازی Push Notification، شناسه FCM دستگاه برای ارسال اعلان‌هایی مانند Price Alert در Backend ثبت می‌شود.

این شناسه برای تبلیغات یا فروش اطلاعات استفاده نمی‌شود.

## داده‌های بازار و محتوای FC27

FCBaz ممکن است برای دریافت اطلاعات بازیکنان، قیمت‌ها، SBC، Evolutions، Objectives و سایر داده‌های مرتبط به سرویس‌های Backend و منابع داده متصل شود.

اگر داده معتبر در دسترس نباشد، برنامه داده ساختگی جایگزین نمی‌کند.

## اشتراک‌گذاری اطلاعات

FCBaz اطلاعات کاربران را برای فروش در اختیار تبلیغ‌دهندگان قرار نمی‌دهد.

اطلاعات فقط در حد لازم برای ارائه قابلیت‌هایی مانند احراز هویت، Cloud Sync و Push Notification با سرویس‌های فنی مرتبط پردازش می‌شوند.

## حذف اطلاعات

کاربر می‌تواند اطلاعات محلی برنامه را با پاک‌کردن داده برنامه یا حذف موارد داخل FCBaz پاک کند.

برای اطلاعات Cloud، پیش از انتشار عمومی باید مسیر حذف حساب و داده Cloud در Backend نهایی فعال و در نسخه عمومی در دسترس باشد.

## امنیت

FCBaz از روش‌هایی مانند Secure Storage برای اطلاعات ورود، HTTPS برای ارتباط Backend و جداسازی Secretهای سرور از اپلیکیشن استفاده می‌کند.

هیچ روش امنیتی تضمین مطلق ایجاد نمی‌کند، اما طراحی برنامه با هدف کاهش دسترسی غیرضروری به اطلاعات انجام شده است.

## سرویس‌های شخص ثالث

بسته به تنظیم Production، برنامه ممکن است از سرویس‌هایی مانند:

- Firebase Cloud Messaging
- Supabase
- سرویس Backend FCBaz
- منابع داده FC27

استفاده کند.

هر سرویس ممکن است سیاست حریم خصوصی مستقل خود را داشته باشد.

## کودکان

FCBaz عمداً برای جمع‌آوری اطلاعات شخصی کودکان طراحی نشده است.

## تغییرات سیاست

در صورت تغییر قابلیت‌های مرتبط با داده یا حساب کاربری، این سیاست نیز بروزرسانی خواهد شد.

## تماس

پشتیبانی و اطلاعات تماس نهایی باید پیش از انتشار عمومی در صفحه Store و Privacy Policy قرار داده شود.
